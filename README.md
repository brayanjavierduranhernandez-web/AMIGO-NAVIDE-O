# 🎄 Amigo Navideño

Herramienta para organizar el sorteo de amigo navideño/secreto de forma sencilla.

## Cómo usarla

1. Abre index.html o visita el [sitio en vivo](https://brayanjavierduranhernandez-web.github.io/AMIGO-NAVIDE-O/)
2. Agrega los nombres de todos los participantes
3. Presiona **Sortear ahora** 🎲
4. Copia el link de cada persona y envíaselo por WhatsApp o correo
5. Cada participante abre su link, presiona el regalo 🎁 y descubre su amigo navideño

## Características

- ✅ Funciona en cualquier dispositivo (celular, PC, tablet)
- ✅ Sin servidor ni base de datos
- ✅ El sorteo garantiza que nadie se saca a sí mismo
- ✅ Tema navideño con animaciones ❄🎄
- ✅ Confetti al revelar el nombre 🎊
